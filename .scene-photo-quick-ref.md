## 🔑 Required Fields for PDF

When creating user_documents records, **MUST** include:
- `storage_path` - Permanent file location
- `public_url` - Public access URL
- **`signed_url`** ← CRITICAL (dataFetcher.js requires this)
- `signed_url_expires_at` - Expiry timestamp

**If signed_url is missing:** Photos will be silently skipped in PDF generation.
